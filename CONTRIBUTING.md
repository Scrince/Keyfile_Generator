# Contributing Guidelines

Thank you for contributing to the Keyfile Tool!

## Contribution Rules
1. **Maintain Portability:** The tool must remain a single, standalone HTML file. Do not add external dependencies (CSS frameworks, JS libraries, etc.).
2. **Security First:** Any changes to the cryptographic logic must be clearly documented and use the `SubtleCrypto` API.
3. **Code Style:** Use 2-space indentation and include comments for complex logic, especially around byte manipulation and buffer handling.

## Process
- Fork the repository and create a feature branch.
- Submit a Pull Request with a detailed explanation of the changes.
- Ensure the decryption logic remains compatible with files generated by previous versions.
