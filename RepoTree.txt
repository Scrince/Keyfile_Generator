Production notes
----------------
- The production source of truth is `Keyfile_Generator.html`. It is a self-contained browser application; the project specifies no external runtime dependencies or platform-specific installers.
- The shipped application copy is the root HTML file itself. There are no separate platform packages or generated application bundles in this repository.
- `scripts/init-and-sign.ps1` creates the release public key, hashes the listed root release files into `docs/SHA256SUMS`, and creates detached `.asc` signatures. The signatures and checksum manifest are release verification artifacts, not application code.
- The app depends on a modern browser with Web Crypto API support. It is designed to run locally as a standalone HTML file.
